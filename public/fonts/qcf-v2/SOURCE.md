# Madinah Mushaf page fonts V2 (QCF V2): source

The 23 page fonts of Juz Amma (Mushaf pages 582-604), `QCF2582.ttf` to `QCF2604.ttf`: the Madinah Mushaf page fonts
V2 of the King Fahd Glorious Quran Printing Complex, as published. The files are not converted, subsetted, renamed
inside or edited in any way.

- Downloaded from `https://raw.githubusercontent.com/nuqayah/qpc-fonts/master/mushaf-v2/QCF2{page}.ttf` (the
  source named for these fonts in the reels project), on 2026-11-11T23:12:13Z (UTC).
- Official download checked on 2026-11-12: not reachable. qurancomplex.gov.sa (relaunched as a beta) lists computer
  fonts but links no font file; `fonts.qurancomplex.gov.sa`, `qurancomplex.gov.sa/TTF/` and
  `download.qurancomplex.gov.sa/resources_dev/` redirect to its home page or return 404. So the files could not be
  compared byte for byte with an official copy.
- Font name table: family `QCF2{page}`, full name `KFGQPC QCF2{page}`, copyright field "Test Font, KFGQPC".
- The glyph codes and page numbers that use these fonts are in `public/qcf-v2.json`
  (`scripts/build-qcf-table.mjs`, which also checks every code against each font's glyph table).
